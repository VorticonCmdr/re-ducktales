## Original evidence

The unpacked resident helper at image4ee1 (`140e:0e01` in Ghidra) loads ES0040,
reads word ES006c and writes DS2229. Original call sites are image4a61
(hardware startup) and3cc5 (difficulty confirmation). The helper and both far
calls are checked against original bytes, including Ghidra's1000-segment
relocation. MCP disassembly prints reversed operands for `8ec0`; its encoding
is MOV ES,AX. No change to the shared emulator session was needed.

The preserved original difficulty scenario captured AX18293 after the BIOS read
and before the seed write. `scripts/verify-difficulty.js` verifies that independent
input and its resulting original menu behavior. This is consumption-boundary
evidence, not a value fitted from the expected final RNG state.

The nominal counter initialization, PIT1193182/divisor65536 and midnight reset
at1800b0 follow the hash-pinned local DOSBox source. Late initial conversion can
exceed that threshold; the first IRQ resets it to zero. Full counter state is
retained before extracting the unsigned16 word. Original PIT sub-tick phase and
optional RTC synchronization are unknown; native clock-phase parity is not claimed.

## Environment contract

`BiosClock` receives local milliseconds since midnight once at creation and an
injected monotonic clock. Browser code supplies Date and performance.now;
simulation reads neither. Elapsed time advances the nominal counter. Explicit
hidden-page pauses freeze the provider with the application. An in-game pause
does not freeze the hardware clock. Restart samples startup again without
resetting the hardware epoch. Ending replay skips startup and samples again
at difficulty confirmation. Unsupported boundaries and invalid/backwards clocks
stop with diagnostics.

Each read records boundary, elapsed time, full counter and returned word in
`#game`'s `data-bios-clock`. These are upstream environment values; they are kept
outside expected game snapshots. There is no host random-number substitution.

`/?bios-seed=0` explicitly supplies the fixed word used by existing recordings.
Other decimal unsigned16 words are accepted; invalid values stop loading. Fixed
word mode supplies the same word at both consumption boundaries and is a replay
environment, not an approximation or recovery mode. Existing browser fixtures
now request their historical zero input explicitly.
