```sh
node scripts/verify-runtime-campaign.js --fresh-browser
```

The current gate requires original build identities, source/primitive evidence,
long jungle component regressions, all194 units, the independent full campaign

Reproduce a new capture without overwriting artifacts:

```sh
python3 scripts/capture-easy-campaign.py --output=.local/new-cave-campaign-producer
python3 scripts/register-mountain-phase-campaign.py --cave-composition --producer=.local/new-cave-campaign-producer --output=.local/new-cave-campaign
```
