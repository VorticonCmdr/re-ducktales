# Fixed native treasure image comparison

The restored port matches all64000 pixels/256000 RGBA bytes of the original
captured at cave1770,before the second treasure page flip. No bytes are excluded,
no tolerance is used,and no frame is searched or selected by similarity.

This one comparison uses the completed first treasure reveal. Original173d calls
EGA0101,which copies each of five row groups before waiting five retraces/group.
After those25 waits,the second composition/party draws on the hidden page before
the fixed1770 stop. The capture's visible completed first page therefore supplies
the target. The original native PNG and its decoded RGBA checksum are pinned
independently;the port's image does not generate either target or input values.
The source/live-vector helper proof remains required by the checker.

The shared carried component starts from original overlay-entry DS and consumes
its separate explicit14-reader-byte stream. Its14 reader states and six treasure
states still compare exactly;all354 publications render. A small read-only
checkpoint hook exposes the visible command page for the pixel check. The default
component checker still runs all three existing negatives when called directly.

[Declaration](../reference/cave-treasure-pixels.json) preserves the original
component/native declarations as unchanged parents. The original capture's
pixelAcceptance:false records its earlier scope;this follow-up admits only the
fixed1770 completed first page. Other cached images and exact scanout timestamps
remain unaligned. This does not establish whole-ending timing,audio device parity,
independent hardware replay or browser acceptance.

```sh
node scripts/compare-cave-treasure-observation.js
node scripts/verify-cave-treasure-pixels.js
```

The pixel checker requires exactly one checkpoint,full320x200 dimensions,original
artifact/decoded checksums and a nonblank target. Altering one target byte and
removing the checkpoint must fail. Native files are never changed by the negative
controls. Missing/corrupt parent,source or image fixtures fail setup.
