# Destination ordinary keyboard integration

The destination dialog now accepts the original I/J/K/M and numeric-keypad
bindings. Physical makes,including browser repeat makes,and releases use the
same ordinary keyboard table as the map. The mode1 reader scans raw slots in
ascending order before alias normalization. Only exact direction3/7 changes
selection;keypad diagonals and center retain the choice. Enter,Space and keypad
Enter produce Fire. The existing seven-count selection/confirmation waits and
caller flushes still own when a choice can be consumed.

The pre-change browser exploration confirmed K was ignored while Right worked.
The old browser filter excluded aliases in this scene;the semantic adapter alone
also lacked their normalization. The historical source-only investigation remains
in`reference/destination-keyboard-investigation.json`.

## Browser boundary and remaining scope

`map-key` now carries physical events in both map modes. A make in the dialog
samples the mode1 reader;releases only update IRQ flags. A make during a blocking
wait is counted as early without reading the table. Those flags survive until
the original caller flush point. Held state alone never refills the table;an
actual new repeat make after the flush can change the choice. Semantic port
buttons remain available. `destination-read` supplies an explicit batch/read
boundary for independently scheduled input groups;it validates the group before
using the same reader.

The browser still prompts consumption from external makes. Autonomous neutral
polls,the original CPU drawing/flush/read window and deferred system-key polling
remain untranslated. This change does not invent a drawing cost or claim complete
destination-routine timing parity. Modifier/system/BIOS-queue behavior outside the
ordinary subset remains separate work.

Five actual browser scenarios pass. The new case exercises letters,keypad
cardinals/diagonals/center,held flags,busy and fresh repeats,Map confirmation,
reopening,travel confirmation and Restart. Debug key flags are published on video
retrace;the test observes one full16ms video interval after readiness before
comparing a flush. No value or state comparison is relaxed. A missing real K make
must fail immediately at choice0 versus1,without timeout. Existing Easy/Hard fixed
input streams still match all64 states,7650 events and2817 flight presentations;
no captured input,timestamp or expected state was edited.
