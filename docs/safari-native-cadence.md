# Original Safari cadence experiment

This recipe targets the original neutral Yellerstone Park loop. It is separate
from the accepted Safari HUD work and browser route. No new original timing
result has yet been accepted.

A fresh private portable emulator starts the supported22-file pairing read-only,
normal core3000 cycles/ms,svga_s3,16MiB and graphics-memory delay off. It uses the
human-configured emulator binary and a generated private API token. HOME,the
shared bridge configuration and the existing8386 session are unchanged. The
owner records shutdown in lifecycle.json even when the experiment fails.

The existing natural security recipe is followed by actual one-pixel map makes
to46,56 (Yellerstone Park,location32,photography variant1),Travel and Fire through
Launchpad. The crash setup requires a naturally nonracing flight;it rejects a
racing launch instead of changing its flag or pretending it reached Safari.
Setup uses execution stops and is not a timing measurement. The actual complete
17548-byte flight body is checked after248 relocations and only exact source-
defined transformations at the91 known hardware-FPU sites. The unchanged live
FPU handler and IVT ownership are also required. No operand/code mask is used.

At the actual overlay7 entry,all7924 original bytes must match after93 actual
loader relocations. The first input must return0 at Main07d7,with mode1,film12
and Main BP-58 equal0. Its caller-owned stack address is retained as a read-only
observation target. The EGA flip/retrace,copy and sprite code spans are checked
against original IT.DRV1. No analysis executable,guest write or restore is used.

After removing every owned breakpoint,a read-only Lua callback samples120
consecutive rendered frames. It reads the driver counter,page flag,film,column,
RNG and Main BP-58. Original0b14 increments that local after the ordinary flip
returns;the existing static source export pins that instruction. This avoids
relying on a one-bit page flag as a frame counter. There are no observation
inputs beyond the completed setup and no expected clock endpoints choose inputs.
The final manual pause must be the only new execution stop. A shot,wrap,missing
sample,truncated Lua result or unfinished input schedule rejects the scenario.

Samples are neither exact CPU checkpoints nor completed-scanout pictures. They
bracket source counter changes at render callbacks. The experiment does not by
itself prove port cadence or whole-level timing parity. Any later port comparison
must declare its initial-state/phase dependency and independently supplied inputs.
